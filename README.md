# 이번 달 위젯

안드로이드 홈 화면에 이번 달 달력과 할 일·디데이를 보여 주는 위젯입니다.

- 앱에서 할 일/디데이를 추가하면 위젯에 바로 반영돼요.
- 달력에서 일정이 있는 날에는 점이 찍혀요. 파란 점은 할 일, 분홍 점은 디데이예요.
- 위젯의 ‹ › 버튼으로 다른 달을 볼 수 있고, 자정이 지나면 이번 달로 돌아와요.

## 꾸미기
- 갤러리 이미지를 스티커로 붙이기 (끌어서 이동, 두 손가락으로 크기·회전, 앞으로/뒤로 순서 변경, 크기 슬라이더, 카드 바깥 여백으로 바탕화면에 삐져나오게)
- 포인트 색 12가지 + 색상·채도·밝기로 직접 고르기, 배경은 기본/단색/사진 (불투명도·어둡게 조절)
- 글자색 자동/어둡게/밝게, 위젯 문구
- 글꼴: 제목과 나머지 글자에 각각 다른 글꼴 파일(.ttf/.otf) 적용, 글자 크기 3단계
- 제목(몇 월) 자리 배경 이미지: 모든 달 공통 또는 달마다 다른 이미지, 얇게/배너처럼 크게
- 일정마다 색·아이콘(이모지), 디데이 매년 반복 (생일·기념일)

## 작업 관리
- 프로젝트: 색·아이콘·마감일·작업 사이트 링크, 진행률(체크리스트 자동 또는 분량 직접 입력)
- 체크리스트 초안 템플릿(회지 / 커뮤) — 마감일에서 거꾸로 날짜 계산, 자유롭게 수정·삭제
- 위젯: 마감 가까운 프로젝트 2개 진행 막대 + D-day, 누르면 작업 사이트 열기
- 위젯에서 ○ 눌러 바로 완료, 못 한 일은 '밀림'으로 이번 달 목록 위에
- 메뉴에서 백업 파일(zip) 만들기 / 복원

## 디자인 (레퍼런스 반영)
- 가장 가까운 디데이 강조 카드
- 제목 모양 3가지(2026년 11월 / November 2026 / 큰 숫자), 요일 한글·영어
- 테두리: 얇은 선 / 스티치(바느질 점선)
- 추천 테마 9종 (라벤더 드림, 딸기우유, 크림 다이어리, 민트 소다, 레몬 스티커, 미니멀 화이트, 모노 나이트, 투명 글래스, 크리스마스)
